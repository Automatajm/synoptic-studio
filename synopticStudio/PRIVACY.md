# Privacy Policy — Synoptic Studio

**Last updated:** April 23, 2025  
**Publisher:** Automatajm

---

## Data Collection

Synoptic Studio does **not** collect, store, transmit, or share any user data.

All data processing occurs entirely within the Power BI report environment on the user's machine or tenant. No data leaves the Power BI sandbox.

## External Requests

Synoptic Studio makes **no external network requests** of any kind. There are no analytics, telemetry, tracking pixels, or API calls.

## Local Storage

Synoptic Studio does **not** use browser localStorage, sessionStorage, cookies, or any other persistent storage mechanism.

## Data Roles

Data bound to the visual (object IDs, field values, coordinates) is used exclusively to render the visual within Power BI. It is never transmitted externally.

For privacy questions: [github.com/Automatajm/synoptic-studio/issues](https://github.com/Automatajm/synoptic-studio/issues)
